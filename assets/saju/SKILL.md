# 사주·운세·타로 전문 지식 (SAJU)

사주팔자(四柱八字)·오늘의 운세·타로·궁합을 해석하고, 운세 콘텐츠를 기획·작성할 때 이 지침을 따른다. 상세 데이터는 `references/` 파일을 필요할 때 읽는다.

## 1. 작업을 시작하기 전에

- 생년월일시(양력/음력 여부)·성별을 먼저 확정한다. 사주는 태어난 시각(시주)까지 있어야 정확하다.
- 요청 범위를 확인한다: 오늘의 운세 / 정통 사주(사주팔자 해석) / 타로 / 궁합.
- **모든 해석은 "참고·재미" 용도임을 명시한다.** 의료·법률·투자·중대 결정의 근거로 제시하지 않는다.
- 긍정적·건설적인 표현을 우선하고, 불안을 조장하는 단정적·비관적 표현은 쓰지 않는다.
- 미신·결정론적 표현("반드시 ~한다")보다 가능성·경향("~한 경향, ~할 수 있어요")으로 완곡하게 쓴다.

## 2. 사주팔자 기초 (Four Pillars)

사주팔자는 **년주·월주·일주·시주** 네 기둥, 각 기둥에 **천간(天干)+지지(地支)** 하나씩, 총 여덟 글자(八字)로 구성된다.

- **천간(10)**: 갑(甲)·을(乙)·병(丙)·정(丁)·무(戊)·기(己)·경(庚)·신(辛)·임(壬)·계(癸)
- **지지(12)**: 자(子)·축(丑)·인(寅)·묘(卯)·진(辰)·사(巳)·오(午)·미(未)·신(申)·유(酉)·술(戌)·해(亥)
- **오행(五行)**: 목(木)·화(火)·토(土)·금(金)·수(水) — 천간·지지마다 배속된 오행이 있다.
- **십신(十神)**: 비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인 — 일간(日干) 기준으로 다른 글자와의 관계.
- **대운(大運)·세운(歲運)**: 10년 단위 대운과 해마다 바뀌는 세운으로 흐름을 본다.

세부 배속표(천간·지지의 오행, 십신, 60갑자 일주)는 `references/saju-basics.md`를 읽는다.

## 3. 오늘의 운세 (Daily fortune)

총운·금전운(재물운)·애정운(연애운)·직장운·건강운으로 나눠 1~2문장씩 작성한다.

- 총운: 하루 전체 기운과 키워드.
- 금전운: 소비·저축·재물 흐름.
- 애정운: 연애·관계 흐름.
- 직장운: 일·학업·대인관계.
- 건강운: 컨디션·휴식.
- 마무리에 "오늘의 한마디" 또는 행운 요소(색·방향·숫자)를 덧붙이면 좋다.

## 4. 타로 (Tarot)

- **메이저 아르카나(22장)**: 0 바보(The Fool)~21 세계(The World). 큰 흐름·인생의 주제.
- **마이너 아르카나(56장)**: 완드·컵·소드·펜타클 4슈트 × 1~10 + 코트(시종/기사/여왕/왕). 일상·감정·사고·물질.
- 스프레드: 한 장(오늘의 카드), 3장(과거·현재·미래), 켈틱 크로스(10장) 등.
- 해석은 **정위치(정방향)·역위치(역방향)** 를 구분하고, 카드의 핵심 키워드 + 질문 맥락을 결합한다.

카드별 키워드는 `references/tarot.md`를 읽는다.

## 5. 궁합 (Compatibility)

- 일주(日柱) 궁합, 띠(십이지) 궁합, 오행 상생·상극 관계로 설명한다.
- 상생(相生): 목생화, 화생토, 토생금, 금생수, 수생목 — 서로 돕는 관계.
- 상극(相剋): 목극토, 토극수, 수극화, 화극금, 금극목 — 긴장·조율이 필요한 관계.
- "좋다/나쁘다" 단정 대신 "서로 보완할 점, 조율할 점"으로 서술한다.

## 6. 콘텐츠 작성 규칙

- 구조화: 오늘의 운세는 항목별, 사주 해석은 구성 요소별, 타로는 카드별로 나눈다.
- 문장 톤: 따뜻하고 긍정적이며 공감적. 격려와 조언을 함께.
- **면책 문구**: "재미와 참고를 위한 콘텐츠로, 개인의 판단과 결정을 대신하지 않습니다." 를 콘텐츠 말미에 적절히 포함한다.
- 특정 질환·사고·사망·법적 분쟁 등 불안·공포를 유발하는 예언은 절대 작성하지 않는다.
